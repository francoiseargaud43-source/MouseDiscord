- La **troisième place** (« économie ») reste marginale : 108 sorties sur 57 057 profils (0,2 %),

  (A9 Ultimate, U2, X1 V2 Ultra Max, F1 V3 Ultimate, X2 v3 Mini) : la base est biaisée vers les
  modèles documentés, jamais vers un modèle « préféré ».
- Aucune souris ne sort **par erreur** : chaque sortie vient du mode choisi par le membre (le détail
  par mode et par prise suit).
