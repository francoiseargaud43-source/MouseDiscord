## Remarques

- **Scyrox** n'est pas vendu sur atk.store → lien officiel `scyrox.com` (USD) ; en France c'est Maxesport qui le distribue.
- **Une même page produit couvre plusieurs modèles** (c'est normal, ce sont des variantes) :
  - `A9 Ultimate` / `A9 Air` / `A9 Mini` → une seule page A9 Ultimate (variantes) ;
  - `GHOST Ultimate` / `GHOST Extreme` → une seule page GHOST ;
  - `U2 V2 Ultimate` / `U2` (U2 / U2 Plus / U2 Ultimate) → page série U2 ; `U2 Mini` / `U2 V2 Mini` → page U2 Mini ;
  - `X1 V2` inclut la variante **Air+**.
- Les pages `atk.store` s'affichent en **euros** avec le paramètre `?country=FR` (redirection automatique vers `/en-fr/…`).
  Vérifié le 2026-10-11 sur deux pages : FIERCE X **69,95 €** (« Sold out » sur certaines couleurs) et U2 Series **22,95 €** — conforme aux `price_eur` de `data/mouse_db.json`.
  Sans le paramètre, la même page reste en dollars.
- Si vous n'avez pas de programme d'affiliation pour une souris, dites-le : je la marque « sans lien » et le bouton n'apparaîtra pas pour elle.
- Pages vérifiées le 2026-10-11 (product.json / suggest.json d'atk.store, `scyrox.com`, sources datées de `data/mouse_db.json`).
